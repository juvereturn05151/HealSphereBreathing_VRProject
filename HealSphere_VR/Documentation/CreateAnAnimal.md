# Create an Animal

Open `Assets/HealSphere/Creation/Scenes/HealSphereCreation.unity` in Unity 6000.4.6f1. Press Play and click the Game view for desktop testing. Use Cat, Dog, Fox, Rabbit, Deer or Owl, or use More to see additional choices. Typing overrides the preset. The existing spatial keyboard opens from the input field and Enter closes it. Select **Create and Breathe** to begin. The first complete four-second inhale and six-second exhale gives a ready model time to remain hidden before formation starts. A slow request continues with guided breathing. The Dream Seed, rabbit, tree and motes use the existing timed breathing reactions. The reveal leads into a final breath and the awakening. **Create Another Friend** starts a new selection, and **Visit My Little Friends** lets you revisit up to three animals from this play session.

The offline catalogue uses local illustrated GLBs for the six primary presets, Elephant and Gorilla. The simple local descriptions support sleeping, seated and standing where corresponding illustrations exist. For more specific requests the recovery screen offers an explicitly labeled illustration, including the prepared cat if the requested species has no local asset. Examples for connected play include *a little sleeping fox*, *a little red panda*, and *a cute baby dragon*. The deterministic prompt parser accepts a bounded catalogue of species and simple pose, appearance and style descriptors. Unsupported words, multi-animal requests and scenery requests return to the recovery choices. Custom generation does not require a conversation or an OpenAI key.

If the picker cannot reach the backend while preparing a supported local animal, it automatically uses the bundled illustration. A reachable backend returns a saved match or starts generation when paid generation is enabled. Start the backend again after rebooting the PC if you want to use the saved library. An earlier APK may still show “Your little friend needs another moment.” Rebuild and reinstall to get the updated recovery behavior on Quest.

## Backend

Use Node 24 or later. From the Backend folder run `npm ci --ignore-scripts` if needed and `npm start`. Use the existing private `.env`; the local access capability is separate from provider keys. Unity reads `healsphere-backend.json` from the device's persistent data directory. For Windows this project uses `%USERPROFILE%/AppData/LocalLow/DefaultCompany/HealSphere_VR/`. Its fields are `url`, `token` and `live`. For desktop the backend typically listens at `http://127.0.0.1:3000`. The app works offline without a connection file. The connection and Tripo keys stay out of scenes and Git.

The authenticated animal preparation endpoint returns a saved model route or a short-lived proposal. The existing creations endpoint deduplicates submissions, checks account balance, applies configured task limits and validates the downloaded GLB.

To allow new animal requests from **Create and Breathe**, set `ENABLE_GENERATION=true` in the private backend configuration and restart the backend. This grants standing permission to spend credits on eligible new requests, subject to the configured task limits. Set `MODEL_REVIEW_MODE=none` to release validated models automatically. When the global switch is off, the existing local per-request receipt is still available as a scoped spending option.

## Scene and validation

### The awakening

After the surface reveal, the animal settles into a low resting pose. The rabbit invites one final guided breath. Warm motes gather on the inhale, then a soft outward pulse and the creation chime mark the end of the exhale. The model stretches, turns gently and moves up to 16 cm toward the player when there is room. The motion works on the imported GLB root, including unrigged models. Facial movement depends on the source asset, so the procedural version uses a body lift and turn.

The rabbit's three scripted voice cues use the existing speech backend and shared narration source. Clips are prepared during creation, and captions carry the sequence if a clip is unavailable at its cue. After the two awakening lines, the animal remains visible through an eight-second quiet hold. **Visit My Little Friends** opens a gallery of the last three friends made in this play session. **Create Another Friend** returns to the picker. The persistent backend model library continues to handle saved-model reuse.

The existing authored panel and buttons display the captions and ending actions. The `AnimalCreationDirector` exposes `Narrator`, `Awakening Prefab`, and `Quiet Seconds` in the Inspector. **Bind Authored Picker** assigns the existing rabbit narrator and the bundled prefab. The saved scene can also resolve them from the same creation root and the Resources prefab. The prefab has separate warm mote and exhale pulse emitters, capped at 36 and 24 particles.

The creation scene uses an `AnimalCreationDirector` on the existing creation root, with the former reflection director disabled in this scene. Its Inspector references the existing creation director, presenter, loader, guided breathing provider, panel CanvasGroup/Image, six authored preset buttons and two authored action buttons. The last two are `PauseButton (1)` and `WellnessButton (1)`, which present **Create and Breathe** and **More**. The existing buttons show preset labels and icons on the picker and recovery or completion labels as needed. The original spatial keyboard prefab remains assigned to the presenter. **HealSphere → Animal Creation → Bind Authored Picker** rebinds the existing controls and attaches the authored art assets.
